# E-Commerce App

A modern, mobile-responsive e-commerce application built with Next.js 15, TypeScript, Tailwind CSS, and integrated with Wix E-Commerce API.

## Features
- **Mobile-Responsive Design:** Optimized for all devices.
- **Product Catalog:** Browse collections and products.
- **Checkout Flow:** Seamless cart and checkout experience.
- **Review System:** Users can leave product reviews.
- **Member Profiles:** View order history and member information.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Shadcn UI
- **Data Fetching:** TanStack Query (React Query)
- **Backend/CMS:** Wix E-Commerce API

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ahamad12/e-comm.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Configure environment variables:**
   Create a `.env` file in the root directory and add your Wix credentials.
4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser.
